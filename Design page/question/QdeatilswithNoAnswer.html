How to optimize Docker multi-stage builds for Node.js microservices?

I'm working on a monorepo with several Node.js microservices and trying to optimize our Docker build process. Currently, each service takes 3–5 minutes to build, which is killing our CI/CD pipeline speed.

Here's my current Dockerfile for one service:

FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["node", "dist/main.js"]

The main issues I'm facing:

1. npm ci reinstalls everything even when only source code changed
2. The final image is 450MB+ — way too large for a microservice
3. Build cache is rarely hit in CI environments
4. How do I properly leverage BuildKit and cache mounts?

I've read about multi-stage builds and Docker layer caching but I'm not sure how to combine them effectively in a monorepo setup with shared packages. Any guidance would be appreciated!
