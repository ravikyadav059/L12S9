How to implement real-time notifications with WebSockets in React?

I'm building a real-time notification system for my React app. I've set up a WebSocket server using Node.js and the ws library, but I'm struggling with the client-side implementation — specifically reconnection logic and state management.

Here's what I have so far on the server side:

const WebSocket = require('ws');
const wss = new WebSocket.Server({ port: 8080 });

wss.on('connection', (ws) => {
  console.log('New client connected');
  ws.on('message', (message) => {
    wss.clients.forEach(client => {
      if (client.readyState === WebSocket.OPEN) {
        client.send(message.toString());
      }
    });
  });
});

My main concerns are: 1. How to handle automatic reconnection when the connection drops? 2. What's the best way to manage WebSocket state in React? 3. How to sync missed messages after reconnection?

Great question! Here's a robust approach using a custom hook with automatic reconnection and message buffering:

function useWebSocket(url) {
  const [socket, setSocket] = useState(null);
  const [isConnected, setIsConnected] = useState(false);
  const reconnectRef = useRef(null);
  const connect = useCallback(() => {
    const ws = new WebSocket(url);
    ws.onopen = () => setIsConnected(true);
    ws.onclose = () => { setIsConnected(false); reconnectRef.current = setTimeout(connect, 3000); };
    ws.onerror = (error) => { console.error('WebSocket error:', error); ws.close(); };
    setSocket(ws);
    return () => { clearTimeout(reconnectRef.current); ws.close(); };
  }, [url]);
  useEffect(() => { const cleanup = connect(); return cleanup; }, [connect]);
  return { socket, isConnected };
}

For state management, I'd recommend using Zustand — it's lightweight and works perfectly with WebSocket state.

I'd suggest using Socket.IO instead of raw WebSockets. It handles reconnection automatically and provides rooms/namespaces:

import { io } from 'socket.io-client';
const socket = io('http://localhost:8080', {
  reconnection: true,
  reconnectionDelay: 1000,
  reconnectionAttempts: 10,
});
socket.on('connect', () => {
  socket.emit('sync', { lastTimestamp: getLastSeenTimestamp() });
});

For state management, I use React Context + useReducer pattern.
